# Progetti Python - Esercizi Base

Raccolta di script ed esercizi sviluppati per fare pratica con i concetti fondamentali di Python: input da terminale, condizioni (`if`/`elif`/`else`), cicli (`while`/`for`) e manipolazione di liste.

## Script inclusi

* **`calcolo-iva.py`**: Calcola l'importo dell'IVA e il prezzo finale partendo da prezzo netto e percentuale.
* **`calcolo-sconto.py`**: Applica una percentuale di sconto al superamento di una soglia di spesa.
* **`cassa-negozio.py`**: Simula un registratore di cassa con inserimento iterativo degli articoli e calcolo di sconti progressivi sul totale.
* **`gestione-voti.py`**: Raccoglie una serie di voti scolastici e calcola media, voto massimo, voto minimo e numero di sufficienze.

## Prerequisiti
* Python 3.x installato

## Esecuzione
Per eseguire uno qualsiasi degli script, apri il terminale nella cartella del progetto e lancia:
`python nome_file.py`
